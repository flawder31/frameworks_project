# Сервис учета показаний нескольких счетчиков

## Назначение
Приложение предназначено для учета и обработки показаний бытовых счетчиков
(электроэнергия, вода, газ). Позволяет фиксировать текущие показания,
рассчитывать расход за период и определять стоимость потребленного ресурса
по заданному тарифу.

## Целевая аудитория
- Владельцы квартир и частных домов, ведущие самостоятельный учет.
- Сотрудники управляющих компаний, принимающие показания у жильцов.
- Коммунальные службы, работающие с первичными данными потребителей.

## Предметная область
Жилищно-коммунальное хозяйство. Учет потребления коммунальных ресурсов
на основе показаний индивидуальных приборов учета (счетчиков).

## Основные сущности
- Счетчик (тип ресурса, единица измерения, тариф)
- Показание (значение, дата снятия)
- Потребитель (владелец счетчика)
- Расход (разница между показаниями)

## Основные функции
1. Проверка корректности введенного показания (не меньше предыдущего).
2. Расчет расхода ресурса между двумя показаниями.
3. Расчет стоимости потребленного ресурса по тарифу.
4. Определение типа счетчика и единицы измерения по его коду.

## План развития
На следующих этапах планируется:
- разработка веб-приложения на Django;
- подключение базы данных;
- реализация пользователей и авторизации;
- разработка REST API;
- контейнеризация приложения (Docker);
- настройка CI/CD.
